# 🔐 Hash Manager

Проста консольна програма на C++ для шифрування та розшифрування англійського тексту у бінарний код.

## 📂 Структура проєкту

### 📄 Hash.hpp
Містить основну логіку шифрування та розшифрування повідомлень.

### 📄 main.cpp
Містить головний код програми:
- меню користувача;
- обробку введення;
- виклик функцій шифрування та розшифрування;
- завершення роботи програми.

## ⚡ Можливості
- 🔒 Шифрування тексту
- 🔓 Розшифрування повідомлень
- 🖥️ Простий консольний інтерфейс

## ▶️ Приклад

```txt
Введіть 1 щоб шифрувати
Введіть 2 щоб розшифрувати

helloworld
1101001010101101011000001101100000110001011000100
```
